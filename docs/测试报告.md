## 3. 测试方法

- 后端使用 Pytest + HTTPX ASGI Transport，集成测试连接真实 PostgreSQL 测试库，每个用例重建表，保证隔离。
- DeepSeek 调用通过假 Provider 注入，验证请求结构、JSON 校验、重试分支、事实护栏与状态机，不产生真实费用。
- 文件上传测试使用真实 PDF / DOCX 字节流，覆盖正常、扫描件、加密、伪文件、超大文件与路径穿越。
- 前端使用 Vitest + Pinia 测试 store 的加载、创建、更新、失败分支；使用 `vue-tsc` 做严格类型检查。
- 容器配置使用 `docker compose config` 做变量插值与服务依赖校验；Dockerfile 与 Nginx 配置待引擎可用后做实机构建验证。

### 4.2 关键验收点

- 四维权重固定为 15% / 20% / 25% / 40%，总分由程序合成，样例总分 71.75 可复现。
- 修改示例原文必须能在简历中找到；改写新增数字自动降级为“需补充事实”。
- 面试题来源无法在简历/JD 中核实时，自动降级为通用行为题。
- 五维评价 80/70/75/60/85 → 单题 74.0；全部答完状态 `completed`，总分 74.0。
- 追问最多两级；第 2 级后不再生成；题目按父题之后插入，顺序正确。
- 跳题、重复作答、结束后再答均返回 409；跨用户访问返回 404。
- 成长分析只统计 `completed` 面试；不同岗位、面试类型、`rubric_version` 不混算。
