# 验收操作流程（边操作 · 边截图）

> 环境：<http://localhost:8080>（Docker Compose，production）
> 用法：从第 1 步按顺序做到第 15 步。每一步先看“页面应出现的引导”，再操作，看到“截图”就顺手截，最后在“结果”处填 `P`（通过）/ `F`（不通过）/ `S`（跳过）。
> 目标：走完一遍，既验证功能，也验证引导是否真的能带人走完流程，同时拿到论文能用的图。
> 如果你已经完成到第 5 步，直接从第 6 步继续；第 6 步提供了两条进入诊断的路径。

## 1. 开始前（5 分钟）

### 1.1 确认服务和数据

浏览器打开 <http://localhost:8080/api/v1/health>，应看到：

```json
{"environment":"production","status":"ok","database":"ok"}
```

如果打不开，在项目根目录执行：

```bash
docker compose --env-file .env.docker ps
```

`db`、`api`、`web` 都应为 `healthy`。健康接口正常即 `F-37` 通过。

容器数据库和本地 5173 开发库是两套数据。目前容器里只有早期验证账号和 1 份测试简历；你的账号看到的是自己的数据。

### 1.2 账号

### 1.4 浏览器与截图

- Chrome 或 Edge，窗口宽度约 1440，缩放 100%。
- 关闭书签栏（`Ctrl+Shift+B`），截图前关闭开发者工具。
- 整页截图：`F12` → `Ctrl+Shift+P` → 输入 `Capture full size screenshot`。
- 同一组截图使用同一个账号、同一份简历“林舟”、同一个岗位，图与图之间才连贯。
- 不要截到 `backend/.env`、终端里的 API Key 或地址栏 token。

### 1.5 时间与费用

| 操作 | 典型耗时 |
|---|---|
| 上传与文本提取 | 1—3 秒 |
| 结构化解析 | 7—40 秒 |
| 四维诊断 | 40—80 秒 |
| 生成 3 道面试题 | 3—20 秒 |
| 单题评价 | 5—20 秒 |
| 复盘报告 | 8—20 秒 |

主流程约 35—45 分钟。完整一场 3 题面试通常产生 6—9 次模型调用（含追问）。

### 1.6 引导检查是什么

这次除了功能和权限，还检查“产品有没有把人带着走”。共 11 项 `G-01`—`G-11`，分散在各个步骤里。流程条只表示当前走到哪一步，不承担跳转；跳转统一使用页面按钮或顶部导航。每项只问一句：**如果我是第一次用的用户，看到这个页面知不知道下一步做什么？**

## 2. 主流程

### 第 1 步　注册、登录与首页（3 分钟）

**操作**

1. 打开 `/auth?mode=register`，用账号 A 注册，昵称填“验收演示”。
2. 注册后会自动登录并进入工作台。
3. 退出登录，直接在地址栏访问 `/resumes`。
4. 用错误密码登录一次，再用正确密码登录。

**页面应出现的引导**

- 登录页说明“账号数据隔离、密码加密存储、换设备记录仍在”，不出现 JWT、Argon2 这类实现术语（G-01）。

**通过标准**

- `F-01` 注册成功、自动登录。
- `F-02` 未登录跳转并回到原页面。

### 第 9 步　作答与追问（8 分钟）

**操作**

1. 第一题输入 100 字以上，包含背景、做法、结果。

- 追问卡片插在父题之后，并标注“追问”。

**通过标准**

- `F-24` 五维评分、单题得分、下一题正常出现，进度更新。
- `F-25` 若触发追问，追问在父题之后，最多两级；未触发也不扣分。

### 第 13 步　权限与隔离（10 分钟）

**自动检查**

在项目根目录执行：

```bash
backend/.venv/Scripts/python.exe docs/验收材料/权限验证.py
```

脚本会创建两个临时账号，跑 24 项越权检查，约 90 秒。预期最后一行：

```text
合计 24 项：PASS 24，FAIL 0
```

## 附录 C：常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 诊断/解析返回 503 | 容器没有加载 API Key | 检查 `.env.docker`，重建 api |
| 诊断超过 1 分钟 | 模型正常耗时 40—80 秒 | 不要重复点击，超时已配置 120 秒 |

| 刷新子页面 404 | Nginx 未加载 SPA fallback | 确认使用 `frontend/nginx.conf` 构建的 web 镜像 |
| 8080 看不到 5173 的数据 | 容器库与开发库独立 | 在 8080 重新上传，或导入开发库数据 |
| 页面还是旧样式 | 浏览器缓存 | `Ctrl+F5` 强制刷新 |
